# tw-processors
This project is made for Virtual Machines & Virtual Processors to run on Turbowarp.

There are still bugs and more things that we need to do, so it can take long.
The things we came up with are:

NouveauFX GPU - Manages the screen using Pen extension.
EssenceFX CPU - Made for math operators and processes. 
EssenceFX GPU - Screen Manager, but the older version.
EssenceFX Ultra CPU - Made for better and more processes.

The EssenceFX CPU (not ultra) had only +, **, *, / and - operators.
We created a new one so people could use NAND, NOR and XOR.

*We are still working on this project, so please be patient.*
